# Vide-frigo — interface

Mode Operate. Direction retenue : une réserve domestique organisée en étiquettes, avec dates visibles et formulaire direct. Fond blanc pour l’usage dans une cuisine éclairée, vert profond pour les actions, caractères système lisibles. Liste de lignes plutôt qu’une grille de cartes. Sur téléphone, ajout avant liste. Aucune navigation ou fonctionnalité décorative. Refus caméra, erreur de stockage, réseau et attente d’envoi explicitement affichés.

Les bonus ajoutent un bouton de partage, une section de rappels et un choix entre les deux versions en cas de conflit. La modification utilise le formulaire existant.
